## About Open Source Lab — Round 2

The **Tamil Nadu Java User Group (TNJUG)** successfully conducted the second round of its **Open Source Lab** initiative at **Kongu Engineering College, Perundurai**.

The clinic is designed to bridge the gap between classroom theory and real-world software engineering by guiding undergraduate engineers through the end-to-end lifecycle of contributing to open-source Java projects.

## Focus Areas

- **Git & GitHub Workflows**: Branching strategies, pull request etiquette, rebasing, and automated CI pipelines.
- **Java Engineering Standards**: Modern OOP design, unit testing with JUnit 5, Mockito, and code style conventions.
- **Community Mentorship**: Pairing students with seasoned industry engineers for code reviews and architectural guidance.
