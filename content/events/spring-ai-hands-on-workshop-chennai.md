## About the Workshop

On January 31, 2026, Tamil Nadu Java User Group conducted an in-person **Spring AI Hands-on Workshop** in Chennai.

The workshop brought together developers to experiment on their laptops, work through technical challenges, discuss architectural patterns, and support one another in real-time hands-on labs.

## Topics Covered

- **Spring AI Architecture**: Core abstractions, LLM integration, and practical model interaction.
- **Model Context Protocol (MCP)**: Connecting enterprise tools, contextual knowledge, and AI agents.
- **Security & Spring Boot**: Model security patterns and enterprise configuration considerations with Spring Boot.
- **Practical Labs**: Participants ran experiments, solved technical errors together, and implemented Spring AI components directly on their machines.
