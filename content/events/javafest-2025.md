### Event Overview

**JavaFest 2025** is the flagship gathering uniting Java professionals, open-source contributors, student developers, and academic champions from across South India.

As part of the Tamil Nadu Java User Group, organizers are coordinating special community delegations from **Coimbatore, Madurai, and Chennai** to participate in full-day tracks at the Infosys Campus.

### What to Expect

- **Next-Gen JVM**: Deep dive into Java 24/25 feature previews, Project Loom virtual threads in production, and Project Leyden startup optimizations.
- **Spring AI in Practice**: Practical orchestration of LLMs, vector search, embeddings, and tool calling within Spring Boot microservices.
- **Student Lightning Rounds**: Grassroots demos from collegiate chapter leads across Tamil Nadu.
- **Peer Networking**: Connect with Java authors, tech leads, hiring managers, and fellow engineers.
