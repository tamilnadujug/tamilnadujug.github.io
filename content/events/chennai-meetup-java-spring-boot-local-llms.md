## About the Meetup

On May 30, 2026, Tamilnadu JUG held a community meetup at Contentstack in Chennai bringing together Java professionals, engineers, and community members for practical technical sessions on local AI integration and software engineering.

## Technical Sessions

### 1. Local LLMs with Java + Ollama
- **Speaker**: Sai Mounik
- **Topic**: *Local LLMs with Java + Ollama: Build Privacy-Focused AI Applications Without Cloud APIs*
- **Focus Areas**: Practical implementations, architecture, and use cases for running open-source models locally; integrating local LLMs with Java applications; preserving privacy; and optimizing AI compute and cloud API costs.

### 2. AI-Driven Changes to the SDLC
- **Speaker**: Anki (associated with Contentstack)
- **Topic**: AI-driven changes to the software development lifecycle (SDLC), exploring how modern AI tooling influences engineering workflows and system delivery.

### 3. Production Engineering in Spring Boot
- **Speaker**: Yagapriyan G (SDE II at Arcadia)
- **Topic**: *Production Engineering Lessons in Spring Boot*
- **Overview**: Practical lessons and architectural insights gained from operating high-scale Spring Boot services in production environments.
