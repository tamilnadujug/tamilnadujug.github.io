## About the Meetup

On February 7, 2026, the **Tamil Nadu Java User Group (TNJUG)** hosted **Modern Programming Paradigms — Venkat Subramaniam Live** at Sri Eshwar College of Engineering in Coimbatore featuring acclaimed author, educator, and Java Champion **Dr. Venkat Subramaniam**.

The event took place with great enthusiasm, delivering an engaging session packed with lively audience interaction, in-depth architectural questions, and an open participatory Q&A.

The discussions explored modern programming paradigms, contrasting traditional Object-Oriented approaches with Data-Oriented Programming in modern Java, alongside insights into AI infrastructure and current industry software engineering practices.

## Schedule & Sessions

### Technical Keynote (10:00 AM – 11:30 AM)
- **Title**: *OOP vs. Data-Oriented Programming: Which One to Choose?*
- **Speaker**: Venkat Subramaniam (Java Champion)
- **Focus**: Examining how modern Java language features (records, sealed types, pattern matching) enable data-oriented design alongside established object-oriented principles.

### Interactive AMA Session (11:30 AM – 1:30 PM)
- An extensive open Ask-Me-Anything (AMA) with attendees exploring software architecture, engineering disciplines, AI infrastructure, and career growth.
