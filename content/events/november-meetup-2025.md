## About the Meetup

The **Tamil Nadu Java User Group (Tamilnadu JUG)** organized a community meetup at Thoughtworks in Coimbatore in November 2025.

The event took place successfully, bringing together software practitioners and Java developers for in-depth technical sessions and peer discussions.

## Confirmed Sessions & Topics

### 1. Spring AI — Practical Usage Notes
- Practical considerations, design patterns, and lessons learned integrating Spring AI within Java services.

### 2. Writing Better APIs with Java
- Idiomatic API design, clean interfaces, maintainability, and robustness in modern Java development.
