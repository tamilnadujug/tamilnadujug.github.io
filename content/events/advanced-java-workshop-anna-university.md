## About the Workshop

In August 2026, **Tamil Nadu Java User Group (TNJUG)** in partnership with **Anna University Chennai** conducted an intensive 5-day state-wide technical workshop on **Advanced Java Programming**.

The program reached hundreds of computer science students and faculty members across affiliated colleges in Tamil Nadu, delivering structured instruction on modern Java engineering principles.

## Curriculum Highlights

- **Modern Java Idioms**: Functional programming, Lambdas, Streams API, and Pattern Matching.
- **Concurrency & Multithreading**: Thread synchronization, ExecutorService, and modern Virtual Threads.
- **Enterprise Foundations**: JDBC, JPA/Hibernate, and modular architecture.
