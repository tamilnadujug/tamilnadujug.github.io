### Overview

**SQLBuilder** is a high-performance Java library designed to construct clean, maintainable SQL queries through a fluent builder pattern. Developed during Phase 2 of the Open Source Lab, the project demonstrates idiomatic Java practices, separation of concerns, and clean data access patterns.

### Industry Showcase

- **EPAM Systems Java AI Meetup**: Introduced by Sathish Kumar Thiyagarajan and presented by student developers **Keerthana Rajendran** and **Sindhu Dhanashekaran** before working industry engineers and architects.
- **Book of Appreciation**: Awarded by TNJUG and Bangalore JUG in recognition of outstanding student presentation and technical troubleshooting during live demonstration.
